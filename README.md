# Library Management System 📚

A database-driven web application built with **Python (Flask)** and **SQLite** to manage library operations, user accounts, and book catalog inventory.

---

## 🚀 Features

- **Dual Dashboard Roles:** Dedicated interfaces for Administrators and Users.
- **Book Circulation:** Check-out, issue, and return tracking with automatic due-date calculations.
- **Member Management:** Student/member account creation and transaction history.
- **Database Utilities:** Automated database initialization and re-seeding scripts.

---

## 🛠️ Tech Stack

- **Backend:** Python 3, Flask, Werkzeug
- **Database:** SQLite
- **Frontend:** HTML5, CSS3, Jinja2 Templates

---

## 🏃 Getting Started

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Initialize the Database
```bash
python init_db.py
```

### 3. Run the Application
```bash
python app.py
```
Access the application at `http://127.0.0.1:5000`.
